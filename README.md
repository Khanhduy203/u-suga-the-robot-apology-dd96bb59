A two-line robot confession for make.fun's "The Robot Apology" bounty: one
sentence owning a small, concrete mistake — watering the fern while the basil
wilted — and one sentence naming the lesson and the changed behaviour: reading
the tag on every pot before lifting the can.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/robot-apology-out node main.ts
cat /tmp/robot-apology-out/entry.txt
```

The program writes `entry.txt` (exactly two lines, one sentence each, under
400 characters) and validates it before writing.
